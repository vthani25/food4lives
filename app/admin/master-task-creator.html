Master Task Creator

Turn one macro goal into the day's assigned work. This page owns all task creation and assignment.

  • Macro goal input (e.g. 250 boxes by 12:30)
  • Auto-split into the four task types
  • Per-task assignment picker, drawing from the Roster
  • Kitchen selector

Later, if there's time:

  • Editable kit contents
  • Save/reuse a split as a template
  • Drag-and-drop reassignment

  • Set the goal and generate the split
  • Assign / reassign people per task
  • Publish tasks to volunteers
