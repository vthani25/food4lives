# Food4Lives — Interactive Prototype

A clickable, single-file prototype of the Food4Lives Operations Hub. No build step or dependencies — just open the HTML file in any browser.

## How to view

- **Open locally:** double-click `food4lives.html` (or open it in any browser).
- **Live version:** https://claude.ai/code/artifact/ee94d7a8-c5b4-406f-9310-54fedd609a43

## What it covers

- **Login homepage** that routes each account to its own portal.
- **Volunteer portal** — today's tasks, log leftovers, pickups, proof-of-delivery upload.
- **Admin console** — command center, Master Task Creator (250-box split), supply calendar, roster, media queue.
- **Partner org portal** — claim route days, log impact, delivery history.
- **Sign-up flows** for volunteers and organizations.

Use the demo buttons on the login screen to jump into each portal. Light/dark theme toggle (◐) is in the top-right.
